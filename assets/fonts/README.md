# Inter

`Inter-Variable.ttf` is the Inter variable font distributed by Google Fonts:

- Source: https://github.com/google/fonts/tree/main/ofl/inter
- Download: https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf
- License: SIL Open Font License 1.1, included as `OFL-Inter.txt`.

It is bundled to render the Open Graph cards reproducibly on Windows, macOS, Linux and Vercel without depending on installed system fonts.
